# Royalty Router

A browser math game about splitting music royalties correctly. Each statement
shows a payout and a contract; you type each stakeholder's dollar amount and
distribute. Watch for fee lines: shares are calculated on what's left after
the distributor or society takes its cut. Eight statements per shift.

Play it live: https://yksanjo.github.io/royalty-router/

Single-file vanilla HTML/CSS/JS. No build step, no dependencies. All tracks,
artists, labels and payouts are fictional.
